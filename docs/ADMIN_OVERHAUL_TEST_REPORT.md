## الهاتف والأمان

اختبارات العرض القائمة والجديدة تستخدم 360 و390 و412 و768 و1280 بكسلاً، مع فحص التمرير الأفقي ولقطات شاشة. المحاكاة ليست اختباراً لجهاز Android فعلي أو لوحة مفاتيحه أو قارئ الشاشة. لا توجد شهادة WCAG 2.2 AA أو نتائج Lighthouse مصطنعة.

يحفظ CI الأدلة تحت browser-evidence لمدة سبعة أيام. تم إصلاح تعارض محدد حقل كلمة المرور في الاختبار، وفصل عناوين عملاء الاختبارات كي تبقى حدود الطلب الحقيقية مفعّلة. كما أصبح اختبار إعادة تشغيل migration قديمة محصوراً داخل transaction تُلغى؛ لا يترك تعريفات RPC قديمة تحل محل تعريفات الصلاحيات الحالية لبقية الاختبارات.

لا تُعدّل الاختبارات لتجاوز فشل وظيفي. الاختبارات الأربعة المشروطة للمصدر المستضاف تبقى معلنة كغير منفذة، ولا تُحسب نجاحاً.

أظهر اختبار الصفحات سلوك notFound الموثق في Next.js: قد يبقى HTTP 200 بعد بدء البث مع noindex وواجهة عدم وجود الصفحة. لذلك تتحقق اختبارات الخصوصية من noindex وغياب عنوان المسودة ونصها فعلياً، مع قبول 200 أو 404 وفق مرحلة البث؛ لا يكفي اختبار كود HTTP وحده.
