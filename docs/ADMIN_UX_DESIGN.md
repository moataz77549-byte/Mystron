# تصميم إدارة ما يسطرون

تحديث 2026-10-21 — العربية RTL، الهاتف والحاسوب.

## الهوية والتنقل

تُحافظ الإدارة على Navy #111D31، Gold #D5A96A، Ivory #F7F3EB، Teal #267E81، Wine #8F4D52، وخط IBM Plex Sans Arabic. القراءة العامة تستخدم خط المقالات دون تحميل محرر الإدارة.

مجموعات الشريط الجانبي قابلة للطي وتُصفّى بحسب الصلاحيات؛ الخادم وRPC يطبّقان التحقق مستقلاً. الوسوم ضمن الإدارة التحريرية، والبلاغات قائمة مستقلة بجانب التعليقات. الحساب يجمع كلمة المرور وPIN دون تغيير أدوار المستخدم أو هوية المالك.

## الإجراءات والحالات

- جميع الكتابات الجديدة تنتظر إقرار API قبل إعلان النجاح، وتمنع الطلبات المتكررة.
- الوسوم: بحث عربي، ترقيم صفحات، عدد المقالات المرئية والقابلة للتعديل، تأكيد واضح قبل الدمج.
- البلاغات: بانتظار المعالجة/تمت المعالجة/الكل؛ إغلاق دون إجراء أو إخفاء/رفض التعليق مع حفظ القرار.
- التعليقات: فلترة على الخادم وترقيم 25 نتيجة، بدلاً من فلترة آخر 100 نتيجة داخل المتصفح.
- الصفحة الرئيسية: سحب بمقبض مخصص، وأزرار نقل للأعلى/الأسفل تعمل باللمس ولوحة المفاتيح، وإعلان الترتيب لقارئ الشاشة.

## الهاتف وإمكانية الوصول

حقول مسماة، أزرار أصلية، مناطق status/alert، ومنع تجاوز عرض الصفحة. اختبارات المتصفح تغطي 360 و390 و412 و768 و1280 بكسلاً. فحص العرض الآلي لا يعادل شهادة WCAG 2.2 AA؛ يلزم أيضاً قبول بشري بقارئ شاشة ولوحة مفاتيح Android.

## تحديث المتابعة — 2026-10-21

أضيف لون القسم كحد زخرفي آمن دون تغيير تباين النص، وتخصص الكاتب في النماذج والعرض العام. صفحة «جلساتي الإدارية» متاحة للمشرف وتعرض حسابه فقط مع تأكيد الإبطال ورسائل عربية وترقيم خادمي.

## متابعة الاعتماد والصفحات — 2026-10-21

أضيفت صفحة إدارة الصفحات الثابتة ضمن مجموعة إدارة الموقع، مع محرر عربي وأدوات أساسية، وعرض حالة المسودة/النشر والإصدار. أضيف فلتر «معتمدة تحريرياً» وقرار اعتماد النسخة الحالية في الاستوديو؛ لا يبقى الوصف معتمداً أثناء وجود تعديلات غير محفوظة.
