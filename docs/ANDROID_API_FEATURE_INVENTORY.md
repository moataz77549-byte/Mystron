Existing administrative APIs are cookie-based. Their browser CSRF / PIN checks
must remain intact. Native administration requires a separately tested bearer
transport sharing the same permission and publishing services; it must not fake
an Origin header or embed a service-role key.

The six pending production migrations remain under PR #4's protected database
release process. This Android branch does not alter that release's head SHA,
approvals, migration ledger, production data, Supabase project or hosting target.
