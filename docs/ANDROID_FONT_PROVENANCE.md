# Bundled Arabic fonts

These original font files are bundled locally; no runtime font service or user
tracking is needed. Platform copyright does not replace their original licenses.

Source: `https://github.com/google/fonts`, commit
`45e3d5269e4a17d823f6d84470bc084dc5ae46f6`.

Both original `OFL.txt` notices are preserved together in
`apps/android/app/src/main/res/raw/font_licenses.txt`, accessible from the native
About → Font licenses screen. IBM Plex Sans Arabic supplies interface typography;
Noto Naskh Arabic supplies article and poetry typography.
