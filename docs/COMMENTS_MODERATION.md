# التعليقات والمراجعة

التعليقات متاحة للزوار على التدوينات العامة المنشورة فقط. تُخزّن بنص عادي وحالة pending؛ لا تظهر قبل قبول محرر مخوّل. الاسم ظاهر بوسم «زائر» ولا يثبت هوية أو صفة إشرافية. البريد اختياري وخاص في private.comment_contacts، ولا يظهر في API القراءة.

حد الجسم 5000 حرف والاسم 100 حرف. تُرفض الروابط HTTP/HTTPS ووسوم HTML؛ تُعرض النصوص عبر React. حقل honeypot وحد مشترك في PostgreSQL يقللان الرسائل الآلية، ولا يمثلان خدمة تصنيف رسائل مزعجة متقدمة. الحد الافتراضي 5 محاولات في الدقيقة لكل مصدر موثوق من Vercel؛ عدم توافر أسرار الخادم يوقف الإرسال بأمان.

الردود تصل إلى عمق ثلاثة مستويات، على تعليق معتمد في التدوينة نفسها. يستطيع المحرر القبول أو الرفض أو الإخفاء أو الحذف الآمن. تعرض صفحة المراجعة بلاغات الزوار؛ الإبلاغ مقيد بالتحقق وحد الطلبات، ويمنع تكرار البلاغ بنفس المعرّف المؤقت. لا تنفذ الصفحة HTML التعليق أو اسم الزائر.

يمكن تعطيل التعليقات لكل تدوينة. إعدادات النشر تحدد السماح الافتراضي ومدة الإغلاق بعد النشر. البريد الاختياري يُحذف بعد 90 يوماً والبلاغات بعد 30 يوماً بمهمة الاحتفاظ. التعليقات العامة المقبولة تبقى محتوى منشوراً إلى أن تُراجع أو تُحذف.
