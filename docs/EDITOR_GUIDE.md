# استوديو التحرير

بعد توثيق الحساب وإسناد دوره بواسطة مشغّل موثوق، افتح /admin/posts/new لإنشاء مسودة، ثم اختر الكاتب والأقسام والقسم الأساسي. لا يمنح إنشاء كاتب في دليل الكتّاب حساب دخول أو صلاحية نشر.

يدعم المحرر العناوين H1–H6، الفقرات، العريض والمائل والتسطير والشطب، الألوان والتمييز، المحاذاة واتجاه RTL/LTR، القوائم والاقتباسات والفواصل والروابط، الجداول، الأكواد، الصور من المكتبة، فيديو YouTube عبر youtube-nocookie، بطاقات التنبيه، كتل الشعر والملاحظات التحريرية. الملاحظات كتل تحريرية؛ ليست نظام حواشٍ مرقّمة تلقائياً. لا يُعاد تشكيل النص أو تصحيح النصوص الدينية أو علامات الترقيم تلقائياً.

يُحفظ محتوى Tiptap JSON بعد توقف التعديل 2.5 ثانية. راقب مؤشر الحفظ، واحفظ قبل تغيير حالة النشر. نسخة المتصفح المحلية مرتبطة بمعرّف المسودة وتبقى عند فشل الشبكة، ويمكن استعادتها بالزر المخصص. لا تعتمد عليها وحدها: localStorage قد يُمسح ولا ينقل المسودة إلى جهاز آخر. يظهر تحذير المتصفح عند مغادرة الصفحة بتعديلات غير محفوظة.

الحفظ يستخدم رقم إصدار. عند VERSION_CONFLICT احتفظ بنسخة المتصفح وأعد تحميل النسخة الحديثة، ثم راجع التعديلات قبل استعادتها. زر سجل النسخ يعرض نسخ قاعدة البيانات؛ الاستعادة لا تنشر تلقائياً. معايير النشر تشمل عنواناً ومحتوى وكاتباً ظاهراً وقسماً أساسياً مضافاً إلى الأقسام المختارة.

تتوفر معاينة الهاتف والكمبيوتر ووضع التركيز، عدادات الكلمات والأحرف ووقت القراءة، وفهرس العناوين. المعاينة تمر عبر renderer الخادم نفسه، ولا تعرض HTML خاماً غير معالج. لصق Word يمر عبر مخطط ProseMirror؛ السكربتات والأنماط غير المسموح بها لا تُخزّن للتنفيذ.

الفيديو محصور بمعرّف YouTube صالح من 11 حرفاً؛ لا توجد استضافة فيديو أو تضمين مواقع عشوائية. دعم الشعر يحفظ فواصل الأسطر والتشكيل داخل كتلة مخصصة. الصور تُختار من مكتبة الوسائط، ويمكن تعيين معرّف صورة الغلاف والمصغرة والمشاركة بشكل مستقل.
