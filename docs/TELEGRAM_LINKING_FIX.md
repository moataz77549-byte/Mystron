## التنفيذ الموروث والتحقق

احتُفظ بإصلاحات PR #2: إنشاء رمز عشوائي، حفظ SHA-256 فقط، رابط لمرة واحدة لمدة خمس دقائق، فحص الإعدادات والجلسة، ميزان مستقل للربط وإلغائه، polling لحالة الاستهلاك، انتهاء صلاحية واضح، وزر فتح البوت.

هذه حالة تشغيل الخادم، وليست إثبات ربط أو نشر كامل. الاختبارات الآلية تغطي عقد الربط وRPC والصلاحيات. ما يزال اختبار استهلاك رابط جديد بالحساب المصرح والنشر والإشعار فعلياً يتطلب بيئة قبول غير إنتاجية وحساب اختبار مصرحاً.
